# Lloydify

Streaming musik tanpa iklan dengan lirik tersinkron, playlist, dan tampilan liquid glass.

Repo ini hanya berisi **file instalasi (APK)** Lloydify untuk Android.

## Unduh

- Halaman unduh: https://website-theta-one-51.vercel.app
- Atau buka [Releases](https://github.com/Zyuuxyncool/lloydify_releases/releases/latest) dan unduh `lloydify-X.Y.Z.apk` terbaru.

## Cara pasang

1. Unduh file `lloydify-X.Y.Z.apk` dari halaman Releases.
2. Buka file tersebut, lalu izinkan pemasangan dari sumber ini saat diminta.
3. Buka Lloydify. Versi baru akan diberi tahu otomatis di dalam aplikasi.

Android 7.0 atau lebih baru. Setiap rilis mencantumkan SHA-256 untuk memastikan file asli.
